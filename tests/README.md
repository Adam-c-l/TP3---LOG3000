# Tests unitaires

## Raison d’être
    Ce module contient les tests unitaires pour l'application Flask.
## Fichiers principaux
    `test_app.py` : Contient les tests pour l'application Flask.
    `test_operators.py` : Contient les tests pour les opérateurs.

## Dépendances ou hypothèses     
    Les tests utilisent pytest pour exécuter les tests.
