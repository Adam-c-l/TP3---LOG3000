# Module Static

## Raison d’être
Ce module contient les ressources statiques de l'application web de calculatrice, principalement les feuilles de style CSS pour l'interface utilisateur.

## Fichiers principaux
- `style.css` : Définit les styles visuels de la calculatrice, y compris la mise en page, les couleurs et les effets.

## Dépendances ou hypothèses
- Le CSS est conçu pour être utilisé avec le template HTML `index.html` dans le module `templates`.
- Assume un navigateur web moderne supportant CSS3.
